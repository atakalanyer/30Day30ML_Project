A 30-day hands-on journey into Machine Learning, Data Science, and Artificial Intelligence.

This repository documents my daily progress as I explore machine learning concepts, work with real-world datasets, build predictive models, and improve my practical skills through small projects.

- Explore Deep Learning and LLM fundamentals.
